### Example Data Issues

Issues have been identified with the result values represented in the Common Safety Displays example files in this folder - see [Issue \#233](https://github.com/cdisc-org/analysis-results-standard/issues/233).

Also, all Excel example data files in this folder were also developed before finalization of the [ARS Template.xlsx](https://github.com/cdisc-org/analysis-results-standard/blob/main/utilities/python/ARS%20Template.xlsx) file, so they may not be compatible with the published Python utility programs that rely on the format of the ARS Template.

The example files in this folder have not been updated to correct issues with result values, or to align with the ARS Template. However, the corresponding files in the [workfiles/examples/ARS v1](https://github.com/cdisc-org/analysis-results-standard/tree/main/workfiles/examples/ARS%20v1) folder have been updated. Please use the updated files for reference/testing.
